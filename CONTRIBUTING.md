# Contributing to Startup-Sarvam

Thanks for your interest in contributing!

## Getting started

```bash
git clone https://github.com/Chaturvediharsh123/Startup-Sarvam.git
cd Startup-Sarvam
pip install -r requirements.txt
```

## Making changes

1. Create a branch: `git checkout -b my-change`.
2. Make your change and add or update tests.
3. Run the tests: `pytest`.
4. Commit with a clear message and open a pull request against `main`.

## Reporting bugs and requesting features

Open an issue describing what you expected, what happened, and how to reproduce it.
For security issues, follow SECURITY.md instead of opening a public issue.
